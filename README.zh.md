使用本工具，你可以轻松为文件夹设置颜色和图标，使文件管理更加直观高效。你可以从 5000+ 符号图标中选择，也可以自定义颜色方案、添加图片图标或 Emoji，还支持添加文字。
打造专属的个性化文件夹，提升视觉层次感与辨识度。

### 功能特点

- 内置 5000+ 符号图标
- 支持图标透明度与大小调整
- 可自定义文件夹图标颜色
- 图标支持文字、Emoji 与图片
- 一键导入文件夹路径至 Dock
- 支持导出为 .icns 图标文件

新增的功能包括符号图标的透明度与大小调整、丰富的文件夹颜色选择、以及快速导入文件夹路径到 Dock。你还可以将自定义的文件夹图标导出为 .icns 格式，方便在其他地方使用。

### 与系统自带的文件夹自定义工具有什么区别？

macOS 自带的「自定义文件夹」可以为单个文件夹加上预设颜色、符号或 Emoji。文件夹颜色来自 Finder 标签，更改颜色时会同时设置对应的 Tag。

| 功能 | 系统自带 | Iconize Folder |
| --- | --- | --- |
| 自定义文字 | — | ✅ |
| 自定义图片 | — | ✅ |
| 批量自定义文件夹 | 一次一个 | ✅ |
| 批量清理文件夹样式 | 一次一个 | ✅ |
| 自定义颜色 | 会同时设置 Tag 颜色 | ✅ 只设置文件夹颜色 |
| 符号图标 | 部分符号 | ✅ 全部符号图标 |
| 颜色吸取 | — | ✅ |
| 文字字体 | — | ✅ |
| 文字 / 符号图标 / 图片位置 | 固定位置 | ✅ 可调整 |
| 文字 / 符号图标颜色 | 符号为压印效果 | ✅ 可单独设置 |
| 导出 .icns | — | ✅ |
| 从粘贴板添加图标 | — | ✅ |

### URL Schemes

使用此 URL Scheme 可以快速打开指定路径的文件夹。例如，`iconizefolder:///Users/wangchujiang/Desktop/test/` 将打开桌面上的 `test` 文件夹。

```url
iconizefolder://<文件夹路径>
iconizefolder:///Users/wangchujiang/Desktop/test/
```
